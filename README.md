# Favorites / Watchlist Feature

## Overview

Implemented a Favorites/Watchlist system for the Movie Recommendation Application.

Users can save movies to their favorites list, view saved movies, and remove them when no longer needed.

## Features Implemented

### Add to Favorites

* Added favorite functionality directly on movie cards.
* Heart icon can be used to add movies to favorites.

### Favorites Page

* Dedicated page to display all saved favorite movies.
* Responsive card layout for desktop and mobile devices.

### Remove Favorites

* Users can remove movies from favorites.
* Favorites list updates immediately after removal.

### Empty State Handling

* Displays a user-friendly message when no favorites exist.

## Concepts Demonstrated

* CRUD Operations

  * Create Favorite
  * Read Favorites
  * Delete Favorite

* API Integration

* State Management

* Conditional Rendering

* Component Reusability

* Routing and Navigation
