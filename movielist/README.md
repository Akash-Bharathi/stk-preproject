MovieList APP

A responsive React movie application built using the OMDb API that allows users to search for movies, browse random movies on the homepage, and manage a personal wishlist.

Features
-Search movies using the OMDb API
-Random movie suggestions on homepage
-Add movies to wishlist
-Prevent duplicate wishlist additions
-Dark and light theme toggle
-Fully responsive layout
-Desktop view with 5 cards per row
-Mobile responsive design with 2 cards per row
